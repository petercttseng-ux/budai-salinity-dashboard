## 一、資料來源

| 變數 | 來源 | 時間解析度 |
|---|---|---|
| 鹽度、水溫、溶氧、pH、懸浮固體、葉綠素、COD、水位 | 嘉義縣環保局 東石／布袋海域水質自動監測站（函附件 1–5） | 5 分鐘 |
| 降雨量、氣溫、相對濕度、風速 | 中央氣象署 布袋 C0M750、東石 C0M710 自動站 | 逐時 |
| 八掌溪、朴子溪徑流量 | **模式推估**（本專案，HBV 型雙線性水庫） | 逐時 → 逐日 |

徑流量推估方法同第一版（水利署公開驗證流量僅至 2025 年），兩流域共用參數：FC = 150 mm、β = 2、LP = 0.7、直接逕流滯時 15 h、基流滯時 30 日、入滲比例 0.35、地形增雨係數 k = 1.5；模式自 5/1 起算。推估逕流係數：八掌溪 0.726、朴子溪 0.736。**絕對量值不應引用為官方流量統計。**

## 二、主要結果

### 布袋站（八掌溪，2026-05-01 ～ 2026-07-21）

| 變數配對 | Pearson r | p | n |
|---|---|---|---|
| 7日累積雨量 → 日均鹽度 | -0.603 | < 0.001 | 81 |
| log₁₀(徑流量) → 日均鹽度 | -0.699 | < 0.001 | 81 |
| 3日累積雨量 → 日均鹽度 | -0.489 | < 0.001 | 81 |
| 日均徑流量 → 日均鹽度 | -0.451 | < 0.001 | 81 |
| 日降雨量 → 日均鹽度 | -0.370 | < 0.001 | 81 |
| 日降雨量 → 日均徑流量 | +0.869 | < 0.001 | 81 |

- 偏相關：控制潮差 r = -0.696；控制當日降雨 r = -0.638（皆 p < 0.001）。
- 複迴歸（鹽度 ~ log₁₀Q + 潮差 + 風速）：R² = 0.497，log₁₀Q 係數 -0.390 psu/decade（p < 0.001）。
- 落後相關：降雨最強於落後 3 日（r = -0.443）；徑流量於落後 0 日最強。
- 事件：6/7 起 10 日 314 mm 梅雨，鹽度降 1.06 psu；6/25 起 319.5 mm 豪雨，降 0.33 psu。

### 東石站（朴子溪，2026-07-01 ～ 2026-08-31）

| 變數配對 | Pearson r | p | n |
|---|---|---|---|
| 7日累積雨量 → 日均鹽度 | -0.198 | 0.123 | 62 |
| log₁₀(徑流量) → 日均鹽度 | -0.185 | 0.149 | 62 |
| 3日累積雨量 → 日均鹽度 | -0.040 | 0.757 | 62 |
| 日均徑流量 → 日均鹽度 | -0.093 | 0.474 | 62 |
| 日降雨量 → 日均鹽度 | -0.070 | 0.586 | 62 |
| 日降雨量 → 日均徑流量 | +0.908 | < 0.001 | 62 |

- 原始相關皆未達顯著；排除存疑之 7/1–7/21 後 log₁₀Q r = -0.277（n = 41）、7 日雨量 r = -0.356（p < 0.05）。
- **控制潮差後**（僅 8 月水位有效，n = 31）：7 日雨量偏相關 r = -0.627（p < 0.001）、log₁₀Q r = -0.453（p = 0.012）。
- 事件：8/20 起 7 日 499 mm 豪雨，日均鹽度 8 日內由 31.77 降至 30.70 psu（−1.07）。

### 與第一版比較

以第一版期間（5/10–7/15）及環保局資料重算布袋站：7 日雨量 r = -0.602（v1 −0.619）、日雨量 -0.363（v1 −0.356），雨量類指標幾乎不變；log₁₀Q 由 −0.537 變為 -0.680，主因模式提前 9 日起算與雨量補值。乾季基流隨時間遞減而與鹽度季節趨勢共變，**徑流指標 r 宜視為上限，雨量類指標為較保守的佐證**。

## 三、限制

1. 兩站資料期間不同季節（布袋：梅雨期；東石：颱風豪雨期），係數不宜直接比較。
2. 布袋站逐日最低鹽度多次落在 31.1 psu 定值，疑感測器下限，以日均值為主要指標。
3. 未納入農業取排水、魚塭換水及風場水位堆疊；模式參數未經實測流量率定。

## 四、資料品質稽核（需函請環保局查明）

## 五、檔案結構

```
index.html               第二版儀表板（單檔、無外部相依、支援深淺色、雙站切換）
load.py                  讀檔：環保局 Big5 水質檔、CWA MH 格式逐時檔
analysis_v2.py           品管、雙流域徑流推估、相關／偏相關／迴歸／事件分析、資料稽核
build_html.py            將結果嵌入 template.html 產生 index.html
template.html            儀表板樣板
results_v2.json          完整統計結果
daily_budai_v2.csv       布袋站逐日彙整（5/1–9/30）
daily_dongshi_v2.csv     東石站逐日彙整（5/1–9/30）
parse_local.py, analysis.py, results.json, daily_final.csv   第一版（2026-09-05）程式與結果，保留供比對
```

重新產製：將原始檔置於 `raw/` 後執行 `python analysis_v2.py && python build_html.py`（需 pandas、numpy、scipy）。
