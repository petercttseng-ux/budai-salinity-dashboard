| 變數 | 來源 | 時間解析度 | 備註 |

## 二、關於徑流量：為何是推估值

經查經濟部水利署「水文資訊網」河川流量歷史資料，**公開驗證流量僅釋出至 2025 年**；
水利署防災資訊網與水利資料開放平台之河川資料為 *即時* 水位，並未提供 2026 年 5–7 月
之歷史逐日流量。故本專案以觀測降雨驅動之連續式概念水文模式推估八掌溪徑流量，
作為淡水入流強度的**相對指標**。絕對量值不應引用為官方流量統計。

**模式結構（HBV 型雙線性水庫）**

- 流域面積 A = 474.74 km²（八掌溪，出海口位於嘉義縣布袋鎮虎尾寮）
- 土壤水分蓄水池：最大蓄水量 FC = 150 mm、入滲遞減指數 β = 2、蒸散應力係數 LP = 0.7
- 有效降雨 65 % 入直接逕流線性水庫（滯時 15 hr）、35 % 入地下水線性水庫（滯時 30 day）
- 潛勢蒸散：Hamon 法（緯度 23.38°N，由氣溫推估）
- 流域面雨量 = 布袋沿海站雨量 × 地形增雨係數 k = 1.5
- 全期推估逕流係數 = 0.62（符合臺灣西南部溪流豐水期合理範圍）

> 相關係數不受 k 之線性縮放影響，時序型態與相關性結論具穩健性。

## 三、主要結果

| 變數配對 | Pearson r | p |
|---|---|---|
| 7 日累積雨量 → 日均鹽度 | **−0.619** | < 0.001 |
| log₁₀(徑流量) → 日均鹽度 | **−0.537** | < 0.001 |
| 3 日累積雨量 → 日均鹽度 | −0.483 | < 0.001 |
| 日均徑流量 → 日均鹽度 | −0.428 | < 0.001 |
| 日降雨量 → 日均鹽度 | −0.356 | 0.003 |
| 日降雨量 → 日均徑流量 | +0.869 | < 0.001 |

- **偏相關**：控制水溫後 log₁₀(徑流量) 與鹽度 r = −0.548（p < 0.001）；
  控制當日降雨後仍達 r = −0.437（p < 0.001）。
- **落後相關**：降雨的最強訊號出現在 **落後 2 日**（r = −0.397）；
  徑流量在 **落後 0 日** 即最強（r = −0.537），符合徑流量已內含降雨遞延與蓄水記憶的物理意義。
- **複迴歸**（鹽度 ~ log₁₀Q + 水溫 + 風速）：R² = 0.345，log₁₀Q 係數 −0.387 psu/decade（p < 0.001）。
- **事件分析**：3 場累積雨量 ≥ 20 mm 事件，鹽度降幅 0.33–1.01 psu。

## 四、限制

1. 布袋港潮汐交換強烈，日均鹽度變幅僅約 1.6 psu，稀釋訊號本就微弱。
2. 逐日鹽度最低值多次落在 31.1–31.2 psu 之定值，疑為感測器下限或量化效應，故以日均值為主要指標。
3. 未納入潮位、風場水位堆疊與嘉南地區農業取排水影響。
4. 分析期間僅 66 日（梅雨至初夏），不足以推論颱風期或全年關係。

```
daily_final.csv    逐日彙整資料集（66 日 × 30 欄）
results.json       完整統計結果（含逐時序列）
```
